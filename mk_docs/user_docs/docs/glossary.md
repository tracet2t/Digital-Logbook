# Glossary

Key terms used across the Digital Logbook platform.

---

## Core Terms

**Activity Log**
: A daily or periodic update submitted by a student describing tasks, results, blockers, and next actions.

**Activity Feed**
: The list of all submitted activity logs shown on the dashboard.

**Invitation**
: A secure email link used to activate a user account.

**Pending Invitation**
: An invitation that has been sent but not accepted.

**Expired Invitation**
: An invitation link that is no longer valid and must be reissued.

**Bulk Upload**
: Inviting multiple users at once by uploading a spreadsheet file instead of sending individual invitations.

**Project Assignment**
: Linking mentors and students to a specific project.

**Feedback Entry**
: A mentor or admin comment attached to an activity log to guide improvement.

**Blocker**
: A problem preventing progress (for example, dependency delay, missing access, or unresolved issue).

**Role-Based Access**
: Permission model where each user sees only the modules and actions allowed by their role.

**Report Export**
: Downloading filtered project/activity data as PDF or CSV for review or sharing.

**Monthly Attendance**
: A calendar view showing which days a student logged activity. Weekends are highlighted in pink.

**Bench**
: The list of approved users who are not yet assigned to any project. Mentor Bench and Mentee Bench are shown on the Onboarding Approval page.

**Onboarding Approval**
: The process where a Super Admin reviews and approves incoming mentor or student applications before they can be assigned to projects.

**Badge**
: An achievement awarded to students for consistent or high-quality activity submissions (e.g. Rising Star).

**Profile Report**
: A full PDF summary of a student's activity history, badges, and progress. Generated from the Profile page.

---

## Role Terms

**Super Admin**
: Platform manager with full control over users, projects, invitations, onboarding, and reports.

**Mentor**
: Reviewer and guide responsible for evaluating student updates and providing feedback.

**Student (Mentee)**
: Contributor who logs daily progress and acts on mentor suggestions.

---

## Status Terms

**Active**
: User or project is currently in use.

**Pending**
: Waiting for review or approval.

**Approved**
: Reviewed and accepted by a mentor or admin.

**Rejected**
: Reviewed and declined. The user may need to resubmit.
