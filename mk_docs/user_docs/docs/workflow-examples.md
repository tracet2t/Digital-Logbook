# Real Workflow Examples

These examples show how the platform is used in real day-to-day scenarios.

---

## Example 1: New Cohort Setup (Super Admin)

### Goal

Prepare a new project batch with mentors and students.

### Flow

1. Create project
2. Send invitations to mentors and students
3. Monitor invitation statuses
4. Assign mentors to project
5. Assign students to project
6. Verify dashboard and reporting visibility

### Success Outcome

All users are active and projects are ready for daily activity tracking.

---

## Example 2: Weekly Mentoring Review (Mentor)

### Goal

Review student activity quality and unblock progress.

### Flow

1. Open assigned students list
2. Filter by latest activity date
3. Review each submitted activity log
4. Add feedback comments with next action
5. Flag repeated blockers for follow-up

### Success Outcome

Students receive clear, prioritized feedback and maintain momentum.

---

## Example 3: Daily Progress Update (Student)

### Goal

Record meaningful daily progress and keep mentor informed.

### Flow

1. Open Activity or Logbook section
2. Add tasks completed
3. Add measurable results
4. Note blockers and risks
5. Define next planned actions
6. Submit log and review mentor feedback later

### Success Outcome

Progress history becomes clear, measurable, and easy to evaluate.

---

## Example 4: Monthly Report Export (Super Admin)

### Goal

Prepare summary report for management review.

### Flow

1. Open Reports page
2. Set filters (project, date range, status)
3. Generate report
4. Validate key metrics
5. Export PDF
6. Share with stakeholders

### Success Outcome

Decision-makers receive reliable project progress snapshots.
