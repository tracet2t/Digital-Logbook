# Security and Privacy

Digital Logbook uses role-based access and operational safeguards to protect user data and project records.

---

## Security Principles

- Least privilege access by role
- Individual account accountability
- Controlled invitation-based onboarding
- Operational review through reports and logs

---

## Account Security Best Practices

### All Users

- Use strong passwords
- Do not reuse passwords across systems
- Log out on shared devices
- Do not share login credentials

### Super Admins

- Remove or disable unused accounts
- Review invitation status and expiration regularly
- Verify role assignments frequently

---

## Data Handling Guidelines

- Activity logs should contain project-relevant information only
- Avoid storing personal sensitive data in free-text fields
- Exported reports should be shared only with authorized stakeholders

---

## Incident Response

If you suspect unauthorized access:

1. Notify Super Admin immediately
2. Reset affected passwords
3. Review recent activity and account assignments
4. Document the incident and actions taken

---

## Privacy Note

Each organization is responsible for local policy compliance regarding retention, processing, and sharing of project and user information.
