# Feature Comparison

Use this page to understand how Digital Logbook capabilities are distributed across roles.

---

## At a Glance

| Capability | Super Admin | Mentor | Student |
|---|---|---|---|
| User invitations | Yes | No | No |
| Project creation | Yes | No | No |
| Project assignment | Yes | Limited view | Limited view |
| Daily activity submissions | No | No | Yes |
| Activity review | Yes | Yes | Own only |
| Feedback authoring | Yes | Yes | No |
| Report export (PDF) | Yes | Limited | No |
| Role management | Yes | No | No |

---

## Recommended Workflow Ownership

| Workflow | Primary Role | Supporting Role |
|---|---|---|
| New user onboarding | Super Admin | Mentor |
| Weekly progress review | Mentor | Student |
| Blocker escalation | Student | Mentor, Super Admin |
| Monthly reporting | Super Admin | Mentor |

---

## Best Fit by Team Scenario

### Training Program

- Super Admin configures projects and cohorts
- Mentors run weekly review cadence
- Students log daily progress and blockers

### Internship Tracking

- Super Admin manages internship projects and supervisors
- Mentors validate deliverables
- Students maintain activity history for assessment

### Multi-Project Academic Teams

- Super Admin monitors cross-project assignments
- Mentors focus on feedback quality
- Students maintain clear next-step planning
