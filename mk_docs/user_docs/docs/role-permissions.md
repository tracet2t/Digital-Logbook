# Role Permissions Matrix

This page clarifies which role can access each core module.

---

## Access Matrix

| Module | Super Admin | Mentor | Student |
|---|---|---|---|
| Dashboard | Full | Full | Full |
| User Management | Full | No | No |
| Invitations | Full | No | No |
| Projects | Full | View Assigned | View Assigned |
| Student List | Full | View Assigned | No |
| Activity Logs | Full | Review | Create and View Own |
| Feedback | Full | Create and View | View |
| Reports | Full | Limited | No |
| Export PDF | Full | Limited | No |

---

## Permission Notes

### Super Admin

- Controls users, roles, invitations, and projects
- Has the broadest reporting and management access

### Mentor

- Sees assigned project data and assigned students
- Reviews activity logs and leaves actionable feedback

### Student

- Focuses on daily activity updates and feedback review
- Access is intentionally limited to protect system integrity

---

## Change Requests

Need permission changes?

1. Contact Super Admin
2. Describe module and required action
3. Include business reason for the access update

---

!!! warning
    Do not share one account across multiple users. Permissions are role-based and tied to individual accountability.
