    Digital Logbook: Complete User Guide¶

    Welcome to Digital Logbook¶

    Welcome to Digital Logbook. This platform is designed to help Super Admins, Mentors, and Students manage projects, track daily activities, monitor progress, and communicate efficiently in one centralized system.

    This guide will help new users understand how to access the platform, navigate the system, and use all major features confidently.

    Getting Started¶

    First Time Account Setup¶

    If you are using Digital Logbook for the first time, follow these steps to activate your account.

    Step 1: Check Your Email¶

    You will receive an invitation email from the Digital Logbook system. Open your email inbox and look for the invitation message.

    If you cannot find the email:

    • Check your Spam or Junk folder
    • Contact the Super Admin and request a new invitation email

    Step 2: Open the Invitation Link¶

    Click the invitation link provided in the email. This link is used to activate your account and complete your registration.

    Step 3: Complete Your Registration¶

    Fill in the required information and create your password. Make sure your password is secure and easy for you to remember. After completing the form, click the Submit button.

    Step 4: Login to the System¶

    Once registration is complete:

    1. Open the login page
    2. Enter your email address
    3. Enter your password
    4. Click Login

    You will now be redirected to your dashboard.

    Daily Login Process¶

    If your account is already activated, follow these steps each time you log in.

    1. Open the login page
    2. Enter your email address
    3. Enter your password
    4. Click Login
    5. Wait for your dashboard to load

    After logging in, use the left sidebar menu to navigate through the system.

    Understanding User Roles¶

    Digital Logbook provides different access levels based on user roles.

    Super Admin¶

    The Super Admin manages the entire platform and controls system operations.

    Main responsibilities include:

    • Managing users
    • Sending invitations
    • Creating projects
    • Assigning mentors and students
    • Monitoring reports and project activities

    Mentor¶

    Mentors are responsible for guiding and monitoring students.

    Main responsibilities include:

    • Reviewing student activities
    • Monitoring student progress
    • Providing feedback and guidance

    Student¶

    Students use the platform to record their daily work and track project progress.

    Main responsibilities include:

    • Creating activity logs
    • Updating project progress
    • Reviewing mentor feedback
    • Improving work based on feedback

    System Navigation¶

    Dashboard¶

    The dashboard provides an overview of important information related to your role. Depending on your role, the dashboard may display:

    • Assigned projects
    • Recent activities
    • Progress summaries
    • Notifications and updates

    Sidebar Navigation¶

    The left sidebar menu is used to access system modules and pages. Available menu items may include:

    • Dashboard
    • Users
    • Projects
    • Reports
    • Activity Logs
    • Feedback Sections

    The available options depend on your assigned role.

    Search and Filters¶

    Some pages contain search bars and filter options. These tools help users quickly find:

    • Projects
    • Students
    • Reports
    • Activities
    • Users

    Pagination¶

    If a page contains many records, the system may divide the information into multiple pages. Use the pagination controls at the bottom of the page to move between pages.

    Super Admin User Guide¶

    User Management¶

    The User Management section allows Super Admins to control user access within the system.

    Sending Invitations¶

    Super Admins can invite users individually or in bulk.

    Single User Invitation¶

    Steps:

    1. Open the Users or Invitations page
    2. Click Invite User
    3. Enter user information
    4. Select the correct role
    5. Send the invitation

    Bulk User Invitation¶

    Bulk invitations allow multiple users to be added at once.

    Steps:

    1. Open the bulk upload section
    2. Upload the required spreadsheet file
    3. Verify user details
    4. Submit the upload
    5. Review validation results

    If errors appear, correct the invalid rows and upload the file again.

    Invitation Status Types¶

    Each invitation will display a status.

    Pending¶

    The invitation has been sent but the user has not accepted it yet.

    Accepted¶

    The user successfully completed registration.

    Expired¶

    The invitation link is no longer valid. If the link has expired, send a new invitation.

    Project Management¶

    Super Admins can create and manage projects within the system.

    Creating a Project¶

    Steps:

    1. Open the Projects page
    2. Click Create Project
    3. Enter project details
    4. Save the project

    Assigning Mentors to Projects¶

    Steps:

    1. Open the selected project
    2. Choose mentor assignment
    3. Select the mentor
    4. Save changes

    Assigning Students to Projects¶

    Steps:

    1. Open the selected project
    2. Choose student assignment
    3. Add students
    4. Save changes

    Assignments can be updated or removed later if necessary.

    Reports and Exports¶

    The Reports section helps generate reports for monitoring and analysis.

    Generating Reports¶

    Steps:

    1. Open the Reports page
    2. Select filters such as:
    3. Date range
    4. Project
    5. Status
    6. Click generate report
    7. Review the generated results

    Exporting Reports¶

    Reports can be downloaded as PDF documents for sharing or record keeping.

    Mentor User Guide¶

    Viewing Assigned Students¶

    Mentors can access students assigned to their projects.

    Steps:

    1. Login to the system
    2. Open the Students section
    3. Review the assigned student list

    Use filters if the student list is large.

    Reviewing Student Activities¶

    Mentors can monitor student work and progress.

    Steps:

    1. Open a student profile or activity page
    2. Review submitted activity logs
    3. Monitor consistency and progress

    Providing Feedback¶

    Mentors can leave feedback on student activities.

    Steps:

    1. Open a student activity entry
    2. Write feedback comments
    3. Save the feedback

    Good feedback should be:

    • Clear
    • Constructive
    • Helpful
    • Action oriented

    Mentors should review student progress regularly.

    Student User Guide¶

    Viewing the Dashboard¶

    Students can use the dashboard to view assigned projects and activity summaries. The dashboard may include:

    • Project details
    • Recent activity logs
    • Progress updates
    • Mentor feedback notifications

    Creating Activity Logs¶

    Students should update their activity logs regularly.

    Adding a New Activity Log¶

    Steps:

    1. Open the Activity or Logbook section
    2. Click Add Activity
    3. Enter activity information

    Include:

    • Tasks completed
    • Results achieved
    • Challenges or blockers faced

    • Next planned actions

    • Save the activity entry

    Viewing Mentor Feedback¶

    Mentors may leave comments and suggestions on activity logs. Students should:

    • Review feedback carefully
    • Improve future work using mentor suggestions
    • Maintain regular updates

    Common Problems and Solutions¶

    I Did Not Receive the Invitation Email¶

    Try the following steps:

    • Check your Spam or Junk folder
    • Confirm your email address with the Super Admin
    • Request the invitation to be sent again

    Invitation Link Is Not Working¶

    Do not worry. The invitation link may have expired. Contact the Super Admin and request a new invitation link. Open the new email invitation and try again.

    I Cannot See Expected Pages or Menus¶

    Possible reasons include:

    • Your role does not have permission to access the module
    • You are not assigned to a project yet

    Contact the Super Admin for assistance.

    I Cannot Find My Data¶

    Try the following steps:

    • Check active filters
    • Clear search fields
    • Review pagination pages
    • Refresh the page

    Best Practices¶

    For All Users¶

    • Review your dashboard regularly
    • Keep information accurate and updated
    • Save updates carefully
    • Logout after using shared devices

    For Super Admins¶

    • Monitor invitation statuses regularly
    • Remove expired invitations when necessary
    • Review project assignments frequently

    For Mentors¶

    • Review student activity consistently
    • Provide useful and actionable feedback
    • Support students who require additional guidance

    For Students¶

    • Update activity logs daily
    • Clearly explain blockers and challenges
    • Read mentor feedback carefully
    • Stay consistent with project updates

    Final Note¶

    Digital Logbook is designed to improve collaboration, activity tracking, and project management for all users. Regular updates, clear communication, and consistent feedback help ensure successful project progress and better learning outcomes for everyone using the platform.
