# Super Admin Guide

## User Management

The User Management section allows Super Admins to control user access within the system.

## Sending Invitations

Super Admins can invite users individually or in bulk.

### Single User Invitation

Steps:

1. Open the Users or Invitations page
2. Click Invite User
3. Enter user information
4. Select the correct role
5. Send the invitation

### Bulk User Invitation

Bulk invitations allow multiple users to be added at once.

Steps:

1. Open the bulk upload section
2. Upload the required spreadsheet file
3. Verify user details
4. Submit the upload
5. Review validation results

If errors appear, correct the invalid rows and upload the file again.

## Invitation Status Types

Each invitation will display a status.

### Pending

The invitation has been sent but the user has not accepted it yet.

### Accepted

The user successfully completed registration.

### Expired

The invitation link is no longer valid.

If the link has expired, send a new invitation.

## Project Management

Super Admins can create and manage projects within the system.

### Creating a Project

Steps:

1. Open the Projects page
2. Click Create Project
3. Enter project details
4. Save the project

### Assigning Mentors to Projects

Steps:

1. Open the selected project
2. Choose mentor assignment
3. Select the mentor
4. Save changes

### Assigning Students to Projects

Steps:

1. Open the selected project
2. Choose student assignment
3. Add students
4. Save changes

Assignments can be updated or removed later if necessary.

## Reports and Exports

The Reports section helps generate reports for monitoring and analysis.

### Generating Reports

Steps:

1. Open the Reports page
2. Select filters such as:
   - Date range
   - Project
   - Status
3. Click generate report
4. Review the generated results

### Exporting Reports

Reports can be downloaded as PDF documents for sharing or record keeping.
