# System Navigation

## Dashboard

The dashboard provides an overview of important information related to your role.

Depending on your role, the dashboard may display:

- Assigned projects
- Recent activities
- Progress summaries
- Notifications and updates

## Sidebar Navigation

The left sidebar menu is used to access system modules and pages.

Available menu items may include:

- Dashboard
- Users
- Projects
- Reports
- Activity Logs
- Feedback Sections

The available options depend on your assigned role.

## Search and Filters

Some pages contain search bars and filter options.

These tools help users quickly find:

- Projects
- Students
- Reports
- Activities
- Users

## Pagination

If a page contains many records, the system may divide the information into multiple pages.

Use the pagination controls at the bottom of the page to move between pages.
