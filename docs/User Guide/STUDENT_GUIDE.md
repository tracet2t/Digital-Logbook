# Student Guide

## Viewing the Dashboard

Students can use the dashboard to view assigned projects and activity summaries.

The dashboard may include:

- Project details
- Recent activity logs
- Progress updates
- Mentor feedback notifications

## Creating Activity Logs

Students should update their activity logs regularly.

### Adding a New Activity Log

Steps:

1. Open the Activity or Logbook section
2. Click Add Activity
3. Enter activity information

Include:

- Tasks completed
- Results achieved
- Challenges or blockers faced
- Next planned actions

4. Save the activity entry

## Viewing Mentor Feedback

Mentors may leave comments and suggestions on activity logs.

Students should:

- Review feedback carefully
- Improve future work using mentor suggestions
- Maintain regular updates
